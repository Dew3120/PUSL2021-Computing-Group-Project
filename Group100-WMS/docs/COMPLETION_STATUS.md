# Completion Status

This project is a JavaFX + MySQL desktop Warehouse Management System for apparel warehouse operations.

## Completed Core Areas

- Login and role-based access control
- Admin user management and audit logs
- Inventory records, low-stock views, and FIFO batch stock deduction
- Inbound purchase order and goods received workflows
- Outbound goods issue workflow with FIFO batch allocation persistence
- Inter-warehouse stock transfer workflow
- Employee directory and profile data
- Attendance compilation, validation, leave requests, and attendance reporting
- Payroll generation and payroll reports
- PDF/Excel exports
- Forecast dashboard and Java-based demand forecast generation from existing demand/history data

## Excluded / Future Scope

- Hardware biometric device integration is intentionally excluded from the completion score.
- The `biometric/` folder remains a future extension area.
